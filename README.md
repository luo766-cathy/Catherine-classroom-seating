## 1. 项目简介

本项目将一个教室座位分配问题建模为 **0-1 整数线性规划（ILP）**，并使用 **SCIP 求解器**（通过 Python 接口 PySCIPOpt）求解。

问题要求在满足 13 条硬性约束的前提下，为 12 名学生安排 20 个座位中的 12 个，使全体学生的总满意度最大。项目采用规范的 Python 项目结构，将数据、约束、求解逻辑分离，便于阅读、测试与扩展。

## 2. 问题描述

某班级有 12 名学生，编号 A–L。教室共 4 排，每排 5 列，共 20 个座位，座位编号如下：

| 排 | 座位号 |
|---|---|
| 第 1 排 | 1 2 3 4 5 |
| 第 2 排 | 6 7 8 9 10 |
| 第 3 排 | 11 12 13 14 15 |
| 第 4 排 | 16 17 18 19 20 |

座位属性：

- 第 1 列和第 5 列靠窗；
- 第 2 列和第 4 列靠过道；
- 第 3 列在中间；
- 相邻座位指左右相邻（同一排、列号差 1）或前后相邻（同一列、排号差 1）。

## 3. 硬性约束

| 编号 | 约束内容 | 模型中的表达方式 |
|---|---|---|
| 1 | 每名学生恰好坐一个座位，每个座位最多坐一名学生 | 对每个学生 `sum_s x[i,s] = 1`；对每个座位 `sum_i x[i,s] <= 1` |
| 2 | A、B 必须坐在前两排 | 将 A、B 在第 3、4 排的变量固定为 0 |
| 3 | C 必须坐在第 1 排 | 将 C 在第 2–4 排的变量固定为 0 |
| 4 | D 和 E 必须左右相邻 | 若 D 坐 s，则 E 必须坐 s 的左右邻座；反向同理 |
| 5 | F 和 G 不能左右相邻，也不能前后相邻 | 对每一对相邻座位 (s,t)，`x[F,s] + x[G,t] <= 1` 及反向 |
| 6 | H 必须靠窗 | 将 H 在第 2、3、4 列的变量固定为 0 |
| 7 | I 必须靠过道 | 将 I 在第 1、3、5 列的变量固定为 0 |
| 8 | J 和 K 必须坐在同一排，但不能相邻 | 对每排两人指示变量相等；同排相邻列对加互斥约束 |
| 9 | L 必须坐在第 3 或第 4 排 | 将 L 在第 1、2 排的变量固定为 0 |
| 10 | 任意一排最多坐 4 名学生 | 对每排 `sum_{i,s in row} x[i,s] <= 4` |
| 11 | 第 2 排至少坐 3 名学生 | `sum_{i,s in row 2} x[i,s] >= 3` |
| 12 | A 和 C 不能坐在同一列 | 对每列 `sum_{s in col} x[A,s] + sum_{s in col} x[C,s] <= 1` |
| 13 | B 和 L 不能坐在同一排 | 对每排 `sum_{s in row} x[B,s] + sum_{s in row} x[L,s] <= 1` |

## 4. 满意度与目标函数

每名学生 i 对不同排、不同列有偏好分数。若学生 i 坐在第 r 排第 c 列，其满意度定义为：

```
满意度(i, r, c) = 排偏好(i, r) + 列偏好(i, c)
```

目标函数为最大化 12 名学生的总满意度：

```
max  sum_i sum_s  score(i, s) * x[i, s]
```

其中 `score(i, s)` 由排偏好与列偏好相加得到。

## 5. 数学模型形式化

**决策变量**：对每个学生 i 和每个座位 s，定义

```
x[i, s] ∈ {0, 1}
```

`x[i,s] = 1` 表示学生 i 坐在座位 s，否则为 0。

**目标**：

```
max  Σ_i Σ_s  score(i, s) · x[i, s]
```

**约束**：即第 3 节表中的 13 条约束，全部写成线性等式或不等式，构成一个标准 0-1 整数线性规划。

**规模**：12 名学生 × 20 个座位 = 240 个 0-1 变量；约束数量由各类约束累加，属于小规模 ILP，SCIP 可在 0 秒内求得最优解。

## 6. 求解器与建模工具

- **SCIP**：一款开源混合整数非线性规划求解器，支持分支定界、割平面、预处理、对称性处理等，适用于整数规划、约束规划等。
- **PySCIPOpt**：SCIP 的官方 Python 接口，可通过 `Model`、`addVar`、`addCons`、`setObjective`、`optimize` 等 API 在 Python 中直接建模与求解。

本项目使用 PySCIPOpt 定义 0-1 变量、逐类添加线性约束、设置最大化目标，并读取最优解。

## 7. 项目结构

```
classroom-seating/
├── main.py              # 程序入口，调用求解流程
├── requirements.txt     # 依赖列表
├── README.md            # 项目说明
├── LICENSE              # MIT 许可证
├── .gitignore           # Git 忽略规则
└── src/
    ├── __init__.py
    ├── data.py          # 学生列表、排/列偏好表、座位行列换算、相邻关系
    ├── constraints.py   # 13 条硬性约束的添加函数
    └── solver.py        # 建立模型、调用 SCIP、输出结果
```

各文件职责：

- `src/data.py`：定义学生列表、排偏好与列偏好字典、座位号与行列的换算、左右/前后相邻关系、满意度计算。
- `src/constraints.py`：将 13 条硬约束逐类封装为函数，统一由 `add_all_constraints` 调用。
- `src/solver.py`：创建 SCIP 模型、生成变量、添加约束、设置目标、求解并格式化输出。
- `main.py`：程序入口，调用 `solve()`。

## 11. 结果校验

逐条核对 13 条硬约束：

- A、B 均在第 1 排（满足前两排）；
- C 在第 1 排；
- D（第2排第4列）与 E（第2排第5列）左右相邻；
- F（第3排第2列）与 G（第2排第3列）既非左右相邻也非前后相邻；
- H（第4排第5列）靠窗；
- I（第2排第2列）靠过道；
- J（第3排第5列）与 K（第3排第1列）同在第 3 排且不相邻；
- L（第4排第2列）在第 4 排；
- 各排人数分别为 3、4、3、2，均不超过 4，第 2 排不少于 3；
- A 在第 1 列、C 在第 3 列，不同列；
- B 在第 1 排、L 在第 4 排，不同排。

全部硬约束均满足。

## 12. 技术要点

- 所有约束均写成线性等式/不等式，模型为纯 0-1 整数线性规划；
- 利用 PySCIPOpt 的 `addCons` 逐类添加约束，代码按数据、约束、求解三层分离；
- 对“D 和 E 左右相邻”“J 和 K 同排不相邻”等逻辑约束，采用邻座指示变量与互斥约束线性化，避免非线性表达；
- SCIP 预处理阶段即完成大量变量固定与约束删除，求解在 0 秒内达到最优；
- 目标函数系数为排偏好与列偏好之和，直接由数据文件计算，便于调整偏好后重跑。
